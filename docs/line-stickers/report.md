# LINE 스탬프 섹션 구현 및 검증 (2026-10-15)

Characters의 `#characters` 앵커를 그대로 유지하고 바로 다음에 `#line-stickers`를 추가했습니다. 기존 폰트·컨테이너·둥근 섹션·CTA·포커스 스타일을 재사용하며, 크림 배경에 민트와 연한 핑크 카드로 구성합니다. 사용자 요청의 일본어 라벨·제목·설명·구매 문구는 HTML 텍스트입니다. CTA는 https://line.me/S/sticker/37139155 를 새 탭에서 열며 `noopener noreferrer`를 지정했습니다. 기존 페이지는 일본어 단일 언어이며 다국어 전환 코드는 없습니다.

## 변경 파일

- `index.html`: 소개 → 4개 미리보기 → 재생 안내 → 구매 CTA와 판매 안내.
- `styles.css`: 새 섹션에 한정한 스타일, 700px 이하 2열 / 그 이상 4열, 비율 유지, 최소 44px 조작 버튼.
- `site.js`: 클릭 시에만 애니메이션 로드, 3초 원본 재생 후 정적 복귀, 정지·재생, 오류 시 정적 복귀, 모션 감소 설정 변경 대응.
- `assets/images/line-sticker-*.webp`: 공식 정적 미리보기 4개와 애니메이션 4개.
- `assets/images/SOURCES.md`, `README.md`: 출처와 동작 안내.
- `docs/line-stickers/`: 출처·해시·프레임 manifest, 브라우저 검사 결과, 폭별 화면 캡처, 이 보고서.

## 실제 판매 에셋

공식 LINE STORE 상품 37139155의 HTML에서 제공하는 LINE CDN 원본을 사용했습니다. 첨부된 네 가지 디자인과 대조했습니다.

| 파일 이름 | 실제 sticker ID | 내용 |
| --- | --- | --- |
| morning | 911235737 | じきゅうちゃん「おはよう〜」 |
| okaneko | 911235753 | おかねこ「じーーーっ」 |
| tamepyon | 911235754 | ためぴょん「えらい！」 |
| friends | 911235760 | 3인「おつかれ〜！」 |

원본 APNG는 변경하지 않았습니다. 370×300 크기, 모든 프레임의 보이는 픽셀, 프레임별 지연 시간, 유한 재생 횟수를 유지해 무손실 animated WebP로 변환했습니다. 각 프레임의 크림 배경 합성 RGB가 원본과 일치하는지 확인했고, 변환 후 모든 프레임의 지연 시간도 원본과 동일합니다. 각 스탬프는 원본대로 3초간 재생됩니다. 생성·재그림·문구 변경·임의 표정 변경·크롭은 없습니다. 정적 버전도 LINE의 공식 static PNG에서 무손실 변환했습니다.

## 성능과 접근성

정적 미리보기 4개 합계 65.9 KiB, 애니메이션 합계 1672.6 KiB입니다. 애니메이션은 원본 합계 2120.2 KiB보다 21.1% 작습니다. 최초 로드에서는 애니메이션 요청이 0건이며, 정적 미리보기도 lazy loading합니다. 사용자가 누른 스탬프만 로드합니다. 외부 JavaScript 의존성을 추가하지 않았습니다. 이미지의 너비·높이·고정 비율로 레이아웃 이동을 방지합니다.

이미지 alt, 키보드 포커스, 네이티브 버튼, 재생 상태 `aria-pressed`, 새 탭 안내를 제공합니다. 모션 감소 설정에서는 정적 이미지와 명확한 일본어 안내만 표시하고 재생 버튼을 숨깁니다. 설정이 재생 중 바뀌어도 즉시 정적 이미지로 복귀합니다. JavaScript가 꺼져도 소개·정적 미리보기·구매 링크는 동작합니다.

## 미해결 및 한계

Safari/WebKit 런타임이 설치되어 있지 않아 해당 브라우저 자동 검증은 수행하지 못했습니다. 실제 iPhone 기기 검증과 현장 성능 수치는 측정하지 않았습니다. 현대 Safari가 지원하는 WebP를 사용하지만 실제 기기의 재생 확인은 추가 검증 대상입니다. 추가 원본 에셋은 필요하지 않습니다. 운영 사이트에 배포하지 않았습니다.
