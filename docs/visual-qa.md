# Visual QA — 2026-10-04

승인된 Website Mockup의 데스크톱/모바일 구성을 실제 브라우저 화면과 비교했습니다. 자동 픽셀 일치 테스트는 아니며, 레이아웃·그림·정보 위계의 육안 비교와 실제 동작 확인입니다.

## 실제 브라우저 검사

| CSS 화면 너비 | 카드 열 수 | 가로 넘침 |
| --- | --- | --- |
| 320px | 1 | 없음 |
| 390px | 1 | 없음 |
| 768px | 2 | 없음 |
| 1280px | 2 | 없음 |

화면 너비와 실제 document 너비를 비교했습니다. 브라우저의 표시 배율을 고려해 실제 CSS 너비를 확인한 값입니다. 각 이야기 카드까지 실제 스크롤해 lazy-loaded artwork도 확인했습니다. 작은 화면에서 숨기는 책 읽는 장면은 다운로드 대기 상태일 수 있으며 의도된 동작입니다. 검사 기록: [responsive-check.json](responsive-check.json).

다음 동작을 실제 클릭으로 확인했습니다.

- 모바일 메뉴 펼치기와 메뉴 항목 선택 후 닫기.
- App Store 준비 안내 dialog 열기/닫기.
- Discovery 결과 펼치기, `aria-expanded` 갱신, 표정 변경, 다시 닫기.
- FAQ 답변 펼치기/닫기.

브라우저에서 보고된 warning/error 로그는 없었습니다. 정적 파일 검사, JavaScript 구문 검사, 공백 오류 검사를 통과했습니다. `prefers-reduced-motion`의 애니메이션/스크롤 해제 규칙은 소스에서 확인했습니다. 실제 iPhone 하드웨어/Safari 검사, VoiceOver, 200% 글자 확대 및 Lighthouse 감사는 수행하지 않았습니다.

## 한계와 시안 차이

- 별도 고해상도/투명 이미지 파일이 제공되지 않아 첨부 보드의 원래 배경과 해상도 한계가 남아 있습니다. 원본 일러스트 추출과 레이아웃 재현까지 완료했고, 고해상도 원본이 생기면 자산 교체로 선명도를 개선할 수 있습니다.
- 헤더 로고는 별도 원본이 없어 기존 じきゅうちゃん 그림과 텍스트로 구성했습니다.
- 캐릭터 소개는 Website Mockup의 일부 포즈보다 Character Master를 우선했습니다.
- Discovery는 사용자가 예시 결과를 펼칠 수 있습니다. 계산·기록·분석 로직은 구현하지 않았습니다.
- 숫자/발견은 모두 표시 예시입니다. App Store/문의 URL은 아직 없고 임의의 URL을 넣지 않았습니다. 개인정보처리방침은 후속 작업에서 하단 `#privacy` 섹션에 작성하고 Footer 링크로 연결했습니다.
- 모바일에서는 가독성을 위해 시안보다 캐릭터와 폰 화면을 크게 표시했습니다.
